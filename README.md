# StreamLive SPA

StreamLive SPA — веб-приложение StreamLive, работающее поверх PHP-сайта. Сборка включает клиент SPA, серверные API-обработчики и совместимый `playerjs.js`.

## Состав

- `streamlive_night/streamspa.php` — основной PHP-файл SPA и API.
- `streamlive_night/playerjs.js` — библиотека плеера из исходной сборки. Не заменяйте её другой версией без отдельной проверки.
- `LICENSE` — лицензия MIT.
- `VALIDATION.txt` — результаты локальных проверок и известные ограничения.

## Установка через FileZilla

1. Сделайте резервную копию текущего `streamspa.php` и `playerjs.js`.
2. Распакуйте архив локально.
3. Загрузите файлы из `streamlive_night/` в соответствующую папку вашего сайта, сохранив текущую структуру каталогов.
4. Не удаляйте и не заменяйте другие PHP-файлы, конфигурацию, папку `includes` или базу данных.
5. Откройте `streamspa.php?api=ping` и проверьте, что API возвращает `ok: true` и сборку `20261120171500`.
6. Войдите в SPA и проверьте основные разделы: каналы, видео, музыку, YouTube, настройки, Services и серверные приложения.
7. Если возникла ошибка, верните резервную копию `streamspa.php` и проверьте PHP error log хостинга.

## Музыка и локальные файлы

Аудио- и другие пользовательские файлы в локальном хранилище сохраняются в IndexedDB браузера. Они не загружаются на сервер этим механизмом. Хранилище изолировано по origin: разные домены/зеркала и разные браузеры не разделяют содержимое IndexedDB автоматически. Серверная квота места не увеличивает физическую квоту браузера.

## YouTube

Поиск выполняется через серверный API YouTube Data API v3. Личный ключ передаётся серверу POST-запросом; общий ключ сервера хранится в базе и не должен возвращаться клиентам. Поисковая квота учитывается отдельно, серверные бафы повышают её, подписка SPA снимает ограничение в рамках текущей логики. Встроенное воспроизведение использует официальный YouTube IFrame Player API.

Cobalt и Piped не объявляются гарантированными резервными проигрывателями в этой сборке: для их полноценной интеграции требуются настроенные и проверенные endpoint'ы/прокси, доступные с вашего хостинга. Публичные инстансы могут отключаться или менять API. Не вводите URL прокси или ключи от сторонних сервисов в публичный репозиторий.

## StreamLive Services

Личные ссылки на сервисы привязаны к аккаунту. В этой сборке сервер проверяет лимит при сохранении: базово один личный сервис, дополнительные места учитывают серверные boost-единицы. Иконка сервиса определяется по favicon домена. Серверные приложения/API Hub остаются отдельным механизмом.

## Совместимость и безопасность

- Не публикуйте API-ключи, пароли, токены сессий и конфигурацию БД.
- После публикации Google API key ограничьте его только YouTube Data API v3 и разрешёнными источниками; если ключ ранее попадал в публичный доступ, замените его.
- Миграции в этой сборке используют `CREATE TABLE IF NOT EXISTS` и безопасные добавления колонок, но резервная копия БД перед обновлением обязательна.
- Для синхронизации данных между зеркалами все зеркала должны использовать одну и ту же базу данных и согласованную конфигурацию авторизации.
- Бан-лист сайта и SPA должен опираться на одну учётную запись/БД. Проверьте блокировку тестового аккаунта на каждом зеркале после установки.
